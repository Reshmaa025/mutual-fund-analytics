# Mutual Fund Analytics Project

## Overview
This project analyzes mutual fund performance, NAV history, SIP inflows, AUM trends, investor transactions, and benchmark indices using Python, Pandas, SQL, and data visualization tools.

## Project Structure

- data/raw
- data/processed
- notebooks
- sql
- dashboard
- reports

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Plotly
- SQLAlchemy
